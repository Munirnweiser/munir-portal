What makes an AI agent an agent

A chatbot answers. An agent acts: it perceives a goal, plans steps, uses tools, remembers what happened, and iterates until the job is done. Three building blocks:

🧰 Tools

Functions the agent can call — run a shell command, query a database, read a log file. Tools turn language into action. This site's desk agent below uses a tiny tool: keyword lookup over the site's content.

🧠 Memory

Short-term memory (this conversation) and long-term memory (facts that persist across sessions). Memory is what lets an agent learn your preferences instead of starting from zero every time.

🔁 Planning loop

Observe → think → act → observe again. The agent breaks a goal into steps, executes one, checks the result, and adjusts. Production agents add guardrails: approvals, rate limits, audit logs.
